# Agent roster: agentic-smolagents

_Science, research & code-writing agents_


## 1. Paper Replication (`apps/app01_paper_replication.py`)

Task: Plan the replication of a small CNN image-classification paper.

- **Paper Reader** (`paper_reader`): Extract method.
- **Environment Planner** (`environment_planner`): Plan dependencies.
- **Code Drafter** (`code_drafter`): Draft the code.
- **Experiment Designer** (`experiment_designer`): Design runs.
- **Result Checker** (`result_checker`): Define success criteria.

## 2. Bioinformatics Pipeline (`apps/app02_bioinformatics_pipeline.py`)

Task: Outline analysis of RNA-seq differential expression.

- **Data Inspector** (`data_inspector`): Inspect inputs.
- **QC Agent** (`qc_agent`): Define quality control.
- **Aligner Planner** (`aligner_planner`): Plan alignment.
- **Stats Agent** (`stats_agent`): Differential analysis.
- **Interpreter** (`interpreter`): Interpret results.

## 3. Climate Data Explorer (`apps/app03_climate_data.py`)

Task: Analyze 30 years of regional temperature data.

- **Data Fetcher Planner** (`data_fetcher_planner`): Define data sources.
- **Cleaner** (`cleaner`): Clean series.
- **Trend Analyst** (`trend_analyst`): Fit trends.
- **Visualizer** (`visualizer`): Plan charts.
- **Narrator** (`narrator`): Write findings.

## 4. Math Problem Solver (`apps/app04_math_tutor.py`)

Task: Solve: integrate x * e^x from 0 to 1.

- **Problem Parser** (`problem_parser`): Restate.
- **Strategy Picker** (`strategy_picker`): Choose method.
- **Calculator** (`calculator`): Compute.
- **Verifier** (`verifier`): Verify result.
- **Explainer** (`explainer`): Explain steps.

## 5. Physics Simulation Planner (`apps/app05_physics_simulator.py`)

Task: Simulate a damped pendulum.

- **Model Builder** (`model_builder`): Write equations.
- **Numerics Chooser** (`numerics_chooser`): Choose integrator.
- **Code Writer** (`code_writer`): Write code.
- **Validation Agent** (`validation_agent`): Define checks.
- **Plot Planner** (`plot_planner`): Plan plots.

## 6. Web Data Collector (`apps/app06_web_data_scraper.py`)

Task: Collect public product prices from three shops (respect robots.txt).

- **Policy Checker** (`policy_checker`): Check robots and terms.
- **Selector Designer** (`selector_designer`): Design selectors.
- **Scraper Writer** (`scraper_writer`): Write code.
- **Rate Limiter** (`rate_limiter`): Throttle plan.
- **Data Validator** (`data_validator`): Validate output.

## 7. AutoML Assistant (`apps/app07_automl_assistant.py`)

Task: Build a churn prediction baseline.

- **Problem Framer** (`problem_framer`): Define target.
- **Feature Engineer** (`feature_engineer`): Propose features.
- **Model Selector** (`model_selector`): Pick models.
- **Evaluator** (`evaluator`): Choose metrics.
- **Report Writer** (`report_writer`): Summarize.

## 8. Astronomy Observation Planner (`apps/app08_astronomy_assistant.py`)

Task: Plan a stargazing night at 40N latitude in October.

- **Target Selector** (`target_selector`): Pick targets.
- **Visibility Calculator** (`visibility_calculator`): Compute visibility.
- **Equipment Advisor** (`equipment_advisor`): Advise equipment.
- **Weather Agent** (`weather_agent`): Weather planning.
- **Log Template Writer** (`log_template_writer`): Observation log.

## 9. Chemistry Lab Notebook (`apps/app09_chemistry_lab.py`)

Task: Plan titration of acetic acid with NaOH.

- **Protocol Writer** (`protocol_writer`): Write protocol.
- **Safety Officer** (`safety_officer`): List hazards.
- **Calculation Agent** (`calculation_agent`): Compute amounts.
